This is a java fullstack web application developed to perform complete CRUD(create,read,update,delete) operations using hibernate ORM and MySQL. This project demonstrates the transition from traditional JDBC to modren ORM techniques.
Technologies Used:Java,Hibernate,MySQL,Servlets&JSP,Maven
Key Features:
1.User Registration:add new users to database using hibernate session mapping.
2.Admin Dashboard:A centralized interface to manage and view all registered users.
3.CRUD logic: Efficiently handles Create,Read,Update,and Delete operations without writing complex SQL queries.
4.Database Persistence: Automated table creation and data handling via hibernate.cfg.xml.
